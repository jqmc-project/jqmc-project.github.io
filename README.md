# jqmc-project.github.io

Source of <https://jqmc-project.github.io/>, built by GitHub Pages with Jekyll.

- `index.html`: the landing page.
- `_data/method_papers.yml`: the method papers listed on the landing page.
- `assets/structures/*.xyz`: the illustrative structures shown in 3D (generated with ASE).

The documentation of each package is published from its own repository, under
<https://jqmc-project.github.io/jQMC/> and <https://jqmc-project.github.io/aiida-jQMC/>.
Do not add top-level folders named `jQMC` or `aiida-jQMC` here: they would shadow those sites.
